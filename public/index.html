    HOW TO PLAY

    1. Same network

    One person runs the Node.js server on their phone-hotspot-connected laptop or PC. Everyone else joins the same Wi-Fi or hotspot and opens the host's address (like http://192.168.1.5:3000) in their browser.

    2. Create a room

    Tap CREATE ROOM, pick a name and avatar. You get a 4-character room code and the address to share. Use the copy buttons.

    3. Join with a code

    Friends tap JOIN ROOM, enter the code and jump into the lobby. 2 to 4 players fit in one room.

    4. The match

    The host starts one round. After a 3-2-1-GO countdown, one random mini-game starts for everyone at once:

    • Reaction Rush – tap when the screen turns green. Early taps cost 1 second each.
    • Dodge Master – drag or use ← → to avoid falling junk. Longest survivor wins.
    • Aim Battle – tap targets for points. Small ones are worth more.
    • Button Smash – hammer the big button for 10 seconds.

    5. Who wins?

    The server checks every score and picks the winner. Ties are settled by a server coin flip. Leaving mid-match disqualifies you.

    6. The Meme Sound Deck

    Only the verified winner can open the deck's controls. Every sound they tap plays on everyone's device, so losers hear it too. Nobody else can trigger sounds. The server enforces this, not the browser.
